# Little Learners School Website

A responsive multi-page school education website for Little Learners Academy.  
The project includes light/dark mode, responsive layouts, sliders, scroll animations, and form validation.

## Pages

- Home
- About Us
- Academics
- Admissions
- Student Life
- Contact Us

## Features

- Responsive design for mobile, tablet, and desktop
- Light and dark theme toggle
- Mobile burger menu
- Swiper sliders
- AOS scroll animations
- Contact form validation using JustValidate
- Tailwind CSS styling

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Vite
- Swiper
- AOS
- JustValidate
